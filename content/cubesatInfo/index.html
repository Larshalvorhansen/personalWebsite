Local use: some browsers block fetch() when index.html is opened directly with file://. The Load JSON file button works as a fallback. For automatic loading, serve this folder, for example with python -m http.server 8000.

The sidetree is generated entirely from tree_location and item_type in the JSON. Add a component to the JSON and its branch appears automatically.
