Export simulation and results

All outputs contain mock data, not engineering calculations
The JSON file stores the input configuration, state diagram, transitions, and demonstration playback. Data-storage totals are calculated from the configured generation rates, storage capacity, and scripted ground-contact windows; they are not validated orbital/link calculations. Transmitted data is removed from storage, and overflow is recorded as rejected data.
