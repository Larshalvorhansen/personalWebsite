Conditional rules

First matching rule wins, evaluated from top to bottom. Drag-and-drop is not implemented in this mockup.

1. Low battery
IF battery % < 20THEN mode A — Idle
2. Ground station contact
IF station visible AND processed data > 0THEN mode D — Downlink
3. Process in eclipse
IF eclipse AND raw data > 0THEN mode C — Processing
4. Imaging opportunity
IF sunlight AND battery % > 40 AND storage % < 80THEN mode B — Imaging

How control decisions work

  1. Read battery, storage, sunlight and station status.
  2. Evaluate the selected schedule, rules or Python policy.
  3. Request a satellite mode and optional actions.
  4. The real simulator would enforce physical energy and storage limits.
Prototype behavior: changing rules does not change the displayed results. Start / Pause / Stop demonstrate UI states, not actual calculations.
