# Bryllupsnettside

Åpne `index.html` i nettleseren, eller legg `index.html`, `save-the-date.html` og hele `assets/`-mappen på samme nivå på webserveren.

## Kortbilder

Bildefilene til de nye kortene lå ikke i vedleggene. Pakken inneholder derfor fungerende utkast som kan erstattes uten å endre HTML:

- `assets/invitasjonskort.png` – kortet som kommer ut av konvolutten.
- `assets/save-the-date-original.jpg` – forsiden som vises både i vendekortet og på egen side.
- `assets/save-the-date-back.png` – baksiden av vendekortet.

Behold filnavnene når dere setter inn de endelige kortene. Bildene vises best i portrettformat med forhold 2:3. Videoen er fortsatt `assets/invitasjon-plassholder.mp4`.

Den første innlastingen spiller videoen og viser konvolutten. Senere besøk går rett til nettsiden; «Spill av invitasjonen på nytt» viser sekvensen igjen. For å se førstegangsvisningen på nytt kan dere også bruke et privat nettleservindu.
